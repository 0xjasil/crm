# CRM

A comprehensive CRM platform with frontend and backend services.

## Project Structure

- `crm.elevate.com/` - Frontend Next.js application
- `crm backend/` - Backend API & Prisma services

## Getting Started

### Backend
```bash
cd "crm backend"
pnpm install
pnpm dev
```

### Frontend
```bash
cd crm.elevate.com
pnpm install
pnpm dev
```
